# AI-Powered Criminal Network Analysis System

AI-powered Investigative Intelligence Graph for Smart India Hackathon.

## Problem Statement

Smart India Hackathon Problem Statement 26189:

AI-Powered Criminal Network Analysis System.

## Project Goal

Build an investigative intelligence platform that integrates structured
and unstructured crime-related data, extracts entities and relationships,
constructs a unified knowledge graph, performs network analysis and anomaly
detection, and presents explainable intelligence through an investigator
dashboard.

## Core Pipeline

Raw Data
→ Ingestion
→ Normalization
→ AI/NLP Extraction
→ Entity Resolution
→ Relationship Extraction
→ Knowledge Graph
→ Graph Analytics
→ Anomaly Detection
→ Explainable Intelligence
→ Investigator Dashboard
