# Frontend

Investigator-facing web application for the AI-Powered Criminal Network Analysis System.

## Responsibilities

The frontend provides:

- Investigator dashboard
- Search
- Interactive network graph
- Entity profiles
- Timelines
- Transaction views
- Suspicious activity alerts
- Alert explanations
- Evidence/source panels
- Network analytics

## Planned Technologies

- React
- Vite
- TypeScript
- Tailwind CSS
- shadcn/ui
- Cytoscape.js
- Recharts
- Axios
