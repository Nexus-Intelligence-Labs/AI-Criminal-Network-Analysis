# Graph

Knowledge graph and network analytics component.

## Responsibilities

The graph layer is responsible for:

- Neo4j graph schema
- Node and relationship modelling
- Graph loading
- Cypher queries
- Network centrality
- PageRank
- Betweenness centrality
- Community detection
- Shortest paths
- Graph similarity
- Network influence analysis

## Planned Technologies

- Neo4j
- Cypher
- Neo4j Graph Data Science
- NetworkX
- Neo4j Python Driver
